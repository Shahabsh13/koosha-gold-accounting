# سامانه جامع حسابداری طلا و جواهر کوشا (Koosha Gold Accounting)

نرم‌افزار تخصصی، مدرن و تحت وب حسابداری طلا، جواهرات و مسکوکات با قابلیت کارکرد کاملاً آفلاین، حسابداری ارزی-وزنی (ریالی و گرمی)، صدور فاکتور رسمی استاندارد و محاسبه هوشمند مالیات بر ارزش افزوده طبق ماده ۲۶ قانون دائمی مالیات.

---

## 💎 امکانات و قابلیت‌های اصلی

- **حسابداری دوگانه (ارزی - وزنی):** ثبت و تسویه همزمان مانده ریالی (تومان) و مانده وزنی (طلای ۱۸ عیار / ۷۵۰) برای تمامی اشخاص و طرف‌حساب‌ها.
- **فرمول استاندارد صنف طلا (ماده ۲۶ ارزش افزوده):**
  - اصل طلا معاف از مالیات بر ارزش افزوده.
  - محاسبه دقیق اجرت ساخت (درصدی یا گرمی)، سود مصوب اتحادیه (۷٪)، و مالیات ۱۰٪ ارزش افزوده فقط روی مجموع اجرت و سود.
- **انواع فاکتورها:** فاکتور فروش طلا، فاکتور خرید طلا، تعویض طلا (دریافت طلای متفرقه و کهنه در برابر طلای نو).
- **مدیریت انبار و کاردکس کالا:** ردیابی وزن، عیار، اجرت، بارکد، دسته‌بندی اقلام و وضعیت موجودی.
- **دفاتر مالی و حسابداری دوبل:** کدینگ سرفصل‌های کل و معین، ثبت اسناد دوبل با شماره دائمی غیرقابل ویرایش و قابلیت چاپ روکش سند رسمی.
- **مدیریت هزینه‌ها و درآمدها:** سرفصل‌بندی هزینه‌های جاری، تعمیرات، خدمات زرگری و درآمدهای متفرقه با نمودارها و شاخص‌های تحلیلی.
- **کارکرد ۱۰۰٪ آفلاین:** عدم وابستگی به سرور و ذخیره‌سازی محلی و ایمن تمام داده‌ها در حافظه مرورگر (LocalStorage / IndexedDB).
- **خروجی تک‌فایلی مستقل (Single-File HTML):** امکان خروجی گرفتن کل برنامه درون یک فایل HTML بدون نیاز به نصب یا اینترنت.

## 🚀 راهنمای نصب و اجرا

### پیش‌نیازها
- Node.js نسخه 18 یا بالاتر
- npm

### مراحل راه‌اندازی:
```bash
# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه محلی
npm run dev

# ساخت نسخه پروداکشن
npm run build

# ساخت نسخه تک‌فایلی مستقل (آفلاین)
npm run build:single
```

## 🛠 تکنولوژی‌ها
- **Frontend:** TypeScript, HTML5, CSS3, Tailwind CSS
- **Bundler:** Vite
- **Offline & Standalone:** `vite-plugin-singlefile`
